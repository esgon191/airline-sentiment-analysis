# airline-sentiment-analysis
Использование ClearML для упрощения экспериментов, улучшения переиспользуемости кода.

## Реализованная функциональность
1. Оркестрация задач на воркеров с GPU
2. Экспорт артефактов, моделей в S3 хранилище
3. UI-сервис для дата-ассессмента
4. API-сервис для инференса по API

## Запуск сервисов
### UI-сервис
Требуется переключиться на ветку `ui`, распаковать zip-чекпоинт в папку local_models/ (модель в репозитории не индексирована) 

```sh
streamlit run ui.py
```
### Inference-сервис
Требуется переключиться на ветку `inference_server`, распаковать zip-чекпоинт в папку local_models/ (модель в репозитории не индексирована)

```sh
docker build -t app . # Единожды или после изменений
docker run -p 8000:8000 app:latest # Каждый раз при запуске
```
