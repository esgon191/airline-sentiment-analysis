# Model Card — Multilingual Sentiment Classifier (BERT)

## Назначение модели
Модель выполняет классификацию тональности текста на три категории:
- negative — отрицательная оценка
- neutral — нейтральная оценка
- positive — положительная оценка

Применение: анализ пользовательских отзывов, мониторинг клиентского опыта, обработка обратной связи в e-commerce и сервисных доменах.

⸻

## Исходные данные
Датасет: пользовательский выборочный набор текстов с разметкой тональности
(формат: text, label)

Категории: negative, neutral, positive

Объём: собственный датасет с пользовательской разметкой.

Предварительная обработка:
- очистка текстов
- нормализация
- фильтрация шумовых примеров
- балансировка меток


## Архитектура модели
Базовая модель:
tabularisai/multilingual-sentiment-analysis — мультиязычный BERT, обученный для задач классификации тональности.

Особенности fine-tuning:
- Полное дообучение модели (full fine-tuning)
- DataCollatorWithPadding для динамического паддинга
- Тренировка через Trainer (HuggingFace Transformers)


## Метрики
Результаты на тестовой выборке:

Метрика	Значение
Accuracy	0.78
F1-macro	0.77

Метрики указывают на сбалансированное качество классификации между всеми тремя классами тональности.
